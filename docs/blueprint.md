# **App Name**: DeutschDisput

## Core Features:

- Argument Generation: Generate ten advantages and ten disadvantages for a selected discussion topic at four CEFR language levels (A1, A2, B1, B2) in German, tailored to each level's grammar and vocabulary.
- Argument Display: Display the generated arguments in a clear, structured format, with collapsible sections for each CEFR level (A1, A2, B1, B2) with clear labels.
- Sentence Saving: Implement a 'Save Sentence' button for each advantage and disadvantage, allowing users to save specific sentences for later review.
- Responsive Design: Ensure the application is responsive and accessible on various devices, with a clean and intuitive interface for German language learners.
- Topic Selection: Provide a list of common discussion topics in German, as provided, for users to select from. Pre-seed the tool with topics.

## Style Guidelines:

- Color-coded CEFR levels: A1 = Blue (#add8e6), A2 = Green (#90ee90), B1 = Orange (#ffb347), B2 = Red (#f08080).
- Accent color: Use a muted yellow (#f0e68c) for interactive elements like buttons and highlights.
- Use large, readable fonts to improve readability for beginner learners. Consider a sans-serif typeface for its clarity.
- Incorporate simple, intuitive icons to represent advantages (e.g., a plus sign) and disadvantages (e.g., a minus sign) for clear visual distinction.
- Employ a card-based layout for each topic and CEFR level, with collapsible/expandable sections for advantages and disadvantages to manage content density.
- Use subtle animations for expanding/collapsing sections and saving sentences to provide visual feedback without being distracting.

## Original User Request:
Create an app or AI tool that helps German learners practice writing and understanding arguments. The tool should allow users to select from a list of common discussion topics (see list below), and then automatically generate ten advantages and ten disadvantages for each topic at four CEFR language levels: A1, A2, B1, and B2.

Each level should reflect the grammar and vocabulary appropriate for that level:

A1 Level: 10 advantages and 10 disadvantages written in simple main clauses using basic vocabulary.

A2 Level: 10 advantages and 10 disadvantages written in simple sentences using connectors like weil, aber, denn.

B1 Level: 10 advantages and 10 disadvantages including subordinate clauses, such as relative clauses and connectors like obwohl, damit, wenn.

B2 Level: 10 advantages and 10 disadvantages with complex sentence structures, including passive voice, subjunctive (Konjunktiv II), and infinitive clauses (um...zu) where suitable.
